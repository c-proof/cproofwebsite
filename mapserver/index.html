CPROOF WMS Map Services

Each endpoint is a WMS service. Enter the URL in a WMS client (SFMC, Glimpse, QGIS) as the service endpoint.

★ Recommended: BCCOG

A single Cloud-Optimized GeoTIFF covering 45–56°N, 145.5–122.2°W, merging GEBCO 2025, the BC 3 arcsec coastal DEM, and high-resolution inshore DEMs. Depths shallower than 50 m are highlighted in amber/orange/red as a shoal warning.

Endpoint Layer name Extent (W, E, S, N) Preview
https://cproof.uvic.ca/wms/BCCOG BCBathy -145.5, -122.2, 45.0, 56.0

Adding to clients

Glimpse: Mission Layer → Add New Custom Layer → Add WMS layer service → enter https://cproof.uvic.ca/wms/BCCOG → select BCBathy → Valid.

SFMC: Login name (upper right) → Map Settings → Map Layer Settings → Create Layer Setting → enter https://cproof.uvic.ca/wms/BCCOG, layer BCBathy, format PNG, WMS version 1.3.

★ Recommended: BC Contours KML

A single KML covering the full BC coast (45–56°N, 145.5–122.2°W) with contours at 50, 100, 200, and 1000 m. Each depth is a separate folder — load the file once and toggle levels in your app. Full-resolution detail is preserved at Barkley Sound and Hakai Pass; elsewhere contours are simplified to ~300 m for a compact file size.

BCContours.kml

Adding to clients

Download the KML file to your device first, then load it via the file picker in your app.

Glimpse: Mission Layer → Add New Custom Layer → Add KML layer → select the downloaded file.

SFMC: Map Settings → Map Layer Settings → Create Layer Setting → KML → select the downloaded file.
